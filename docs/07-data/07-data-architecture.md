# 07-data — Data Architecture

**Document ID:** DATA-001

## Purpose
Defines logical data architecture, ownership, governance, lifecycle, and integration principles for ARQA.

## Core Principles
- Single source of truth.
- Domain ownership.
- Data classification.
- Auditability.
- Secure storage.
- Lifecycle management.

## Logical Layers
- Operational data
- Analytical data
- Reference data
- Metadata
- Audit data

## Governance
Every dataset must define owner, retention policy, sensitivity, backup strategy, and access policy.
